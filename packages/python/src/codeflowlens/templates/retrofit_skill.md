# CodeFlowLens 주석 소급 작업

기존 코드에 비즈니스 주석을 채우는 절차. **룰 전문은 AGENTS.md의 "CodeFlowLens 주석 룰" 섹션 참고.**

## 절차

1. `codeflowlens check --json` 실행 → `violations` 배열이 작업 목록이다.
   - `target`이 `<파일>::<함수/클래스>`, `missing`이 채울 라벨.
2. 파일 단위로 묶어서 처리한다. 각 대상의 **코드를 실제로 읽고 의미를 이해한 뒤** 주석을 쓴다.
   - 함수: `개요`(무엇을 하는가, 비즈니스 관점 한 문장) + `로직`(어떤 순서로 하는가) + 필요 시 `참고`(비즈니스 규칙).
   - 엔티티: `개요` + `파라미터:` 아래 `- 필드명: 설명` 목록 + 필요 시 `참고`.
   - 코드 구조 설명("X를 호출한다") 금지 — 비즈니스 의미("재고를 차감한다")로 쓴다.
3. 기존 docstring이 있으면 내용을 보존하며 라벨 형식으로 재구성한다. 코드 로직은 절대 바꾸지 않는다.
4. 파일 몇 개 처리할 때마다 `codeflowlens check`로 진행 상황을 확인한다.
5. 전부 통과하면 `codeflowlens scan`으로 코드맵을 갱신하고 결과를 보고한다.

## 주의

- 의미를 확신할 수 없는 코드는 추측으로 쓰지 말고 "확인 필요" 목록으로 보고한다.
- 테스트/헬퍼(`_` 시작)는 `개요`만 있으면 통과한다 — 과도하게 쓰지 않는다.
